## How to use

- **Indicative, not a pixel specification.** *Wireframe-plus*: real layout and texts,
  colours from DD-017, the platform's default font.
- **Language:** explanations in English; screen texts in Dutch, as in the app (`app_nl.arb`).
- **Viewing:** open the `.html` file in a browser (works offline) or look at the `.png`.
- **Sizes:** phone 390×844 dp; Windows 1280×760.
- **Sample data** is fictional.
- The PNG is rendered from the HTML with headless Chrome (`--window-size=1400,2250` for 01, `1400,3050` for 02, `1400,3120` for 03, `1400,2300` for 04, `1400,2950` for 05, `1400,3780` for 06, `1400,3250` for 07, `1400,3100` for 08, `1460,3700` for 04b, `1400,2920` for 09, `1400,2750` for 10, `1400,2010` for 11, `1400,3400` for 12, `1400,3000` for 13, `1400,4200` for 15, `1400,1850` for 16, `1400,3640` for 17, `1700,1200` for 19, `1760,2480` for 20, `1760,1980` for 21, `1360,1820` for 22, `1400,4050` for 23).
