Deadline reminders (T4.1) – sketch, screen 16

Indicative, not a pixel specification. Screen texts are Dutch, as in the app (app_nl.arb). Sample data is fictional; today is Friday 9 October 2026. Orange outline = new. Already decided (PO, 04-10-2026; AC REQ-020, DD-005): a deadline is a date (Q24), the reminder comes on that day at a set time, by default 09:00, through an inexact alarm (window 10 minutes, SPEC Q38; no exact-alarm permission); one notification per day, with the titles (at most five) or, for one item, its title; titles are shown in the notification, never written to disk; no repeated reminders for overdue items (they are on Vandaag); a tap opens the item, or Vandaag when there are more; the notification permission is asked only at the first deadline. Android only for now; Windows follows in T4.5. Decided (PO, 04-10-2026): (a)–(d) all as proposed; see DESIGN.md, DD-005 and DD-018 point 16.

  1. Lock screen (decided): a public version with only the count ("3 deadlines vandaag", or "Deadline vandaag").
  2. After a refusal (decided): once a message "Zonder meldingen zie je deadlines op Vandaag" with Instellingen (Android's settings for Offload). The app never asks again by itself; Settings shows the state (3).
  3. Default (decided): on. The question comes only at the first deadline, so nobody gets a notification without having said yes.
  4. Windows (decided): the section is not shown on Windows until T4.5, so it promises nothing it cannot do yet.
