Navigation and the Windows two panes (T2.6) – Q5b sketch, screen 5

The last screen of design round Q5b. Indicative, not a pixel specification. Screen texts are Dutch, as in the app (app_nl.arb); colours follow DD-017. Already decided (DD-011): five destinations in the order Vandaag · Inbox · Overzicht · Projecten · Mensen, start on Vandaag; Android a bottom bar with a capture button; Windows a side bar (rail) with the list on the left and the item detail on the right; search reachable everywhere, not a destination; triage is a mode. Open for the PO: (1) what the bar shows while only Vandaag and Inbox are built; (2) where capture, search and settings sit on Windows (variant A or B); (3) what a narrow window does. Today in the samples: Monday 28 September.
Decided (PO, 29-09-2026): variant A; only built destinations (now Vandaag and Inbox); two panes from 840 px; the keys and behaviour below as proposed. See DESIGN.md, DD-018 point 5.

Windows · variant A: the rail carries the actions

Capture as the ＋ button at the top of the rail (as in Material's navigation rail; Ctrl+N, and Win+Shift+B keeps working from anywhere), Settings at the bottom of the rail, and a search field above the list, always visible (Ctrl+F). The list pane only shows the destination: title, inbox line, cards. The detail on the right is the item detail of DD-018 point 1, unchanged.

Behaviour (both variants)

  • Start on Vandaag (DD-011). The app remembers nothing between starts; the start screen is always Vandaag. The widget, share target and Win+Shift+B keep opening only the capture window (hard rule 7).
  • Inbox badge: the number of unprocessed items, in the bar/rail; no badge at zero.
  • Keys on Windows (while no text field has the focus): ↑/↓ select a card, Enter puts the focus in the detail, Esc goes back to the list, Ctrl+Enter completes (as in the detail), Del moves to the trash; both with undo, and the selection moves to the next card. Proposal: Ctrl+1/2 switch destination, Ctrl+N captures, Ctrl+F searches.
  • Triage on Windows uses the width of both panes; the rail stays, Esc ends it and returns to where it was started (Vandaag or Inbox).
  • Search results open in the same place as a list: on Windows in the list pane, with the detail beside it.
  • The temporary switch "Ook verwerkte items tonen" stays in the Inbox until Projecten exists (M3).
  • Android back: from Inbox back to Vandaag; from Vandaag the app closes.
