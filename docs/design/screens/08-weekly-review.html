Unlike triage, which takes both panes, the review stays in the list pane and the detail pane shows the selected item, so you can read or edit it while reviewing. Behaviour and the open points

  • Stale (AC REQ-051): an open item (not done or archived) whose last touch is X weeks ago or longer. "Last touch" is worked out, never stored: the later of the moment in the item's HLC and reviewed_at, the moment of the last Houden / Wacht nog. reviewed_at is a user fact that is synchronised: schema v6, with a migration. Opening an item does not count.
  • Age as text on every card ("7 wk", "9 d"), orange from 6 weeks (the oldest class of the later Overview).
  • Undo: Afgerond, Archiveren and Prullenbak each with undo in a message, as elsewhere.
  • Ending: ✕ or Esc ends at any moment; nothing is remembered. After step 4 an end screen "Klaar ✓" with what you did (n kept, n archived …) and back to Vandaag.
  • (a) Variant A, one step per screen (proposal: clear where you are, the same on phone and Windows), or B, one page.
  • (b) A step with nothing to do is skipped and shown ✓ on the start screen (proposal).
  • (c) "Wacht nog" marks the card done but keeps it in view, so you see what you went through (proposal); the alternative is that it disappears.
  • (d) Notes count for stale as well (proposal: yes; an old note can be archived too), or only actions.
  • (e) X is a device setting for now (proposal), synchronised later with the other settings (M9).
  • (f) Windows key to start: Ctrl+Shift+W (proposal; Ctrl+W often closes a window).
  • Later: the weekly reminder (T4.4), "Terugzien op…" (T4.2), the Overview embedded in the review (T10.7).
