Triage card (T2.4) – Q5b sketch, screen 3

Triage mode: the inbox card by card, each card to one of six destinations (AC REQ-010): task, idea, request, waiting for, reference, trash. Indicative, not a pixel specification. Screen texts are Dutch, as in the app (app_nl.arb); colours follow DD-017. PO decisions already made (28-09-2026): on Windows the number keys 1–5 for the destinations and Del for the trash (as in the detail); skipping a card is allowed (the item stays in the inbox); swiping in the inbox list (Q26) goes the same way as here: left = trash. The PO's first feeling was that task is the most used destination, hence Taak under the right swipe in A and C. The three variants differ in the swipes. Sample card: the shared mail from screen 2.
Decided (PO, 28-09-2026): variant B (swipe right = skip, swipe left = trash, the six destinations as a 3×2 grid of buttons), with the common parts below. See DESIGN.md, DD-018 point 3.

A · Two swipes + a row of buttons

Right = Taak, left = Prullenbak. Below the card one row with all six destinations; Overslaan as a text button. The most common choice is one swipe, everything else one tap.

Windows: triage in the main pane, fully with the keyboard

No mouse swipes (AC REQ-010). Number keys for the destinations, the same in every language; the number is shown on each button. Del = trash as in the detail; → or Space = skip; Ctrl+Z = undo the last choice; Enter = open the item; Esc = stop triage. The person question is the same suggestion list, operated with arrows/Enter/Esc (DD-004 point 9).

  • The card shows the whole text (a long text scrolls inside the card), the chips from the stored tokens, the relative time and the duplicate hint (REQ-053). Openen goes to the item detail and comes back to the same card.
  • Destinations (AC REQ-010): Taak → type task, status active; Idee → type idea, active; Verzoek → type request, active, asks who; Wacht op → status waiting, asks for whom, type unchanged; Referentie → type note, active; Prullenbak → tombstone. Referentie is only the label of the button.
  • Undo is always possible right after a choice; a trashed item is never deleted for good (tombstone, DD-003).
  • Progress "3 van 12" counts the inbox at the start; new captures during triage come at the end.
  • Trash is grey, not orange: orange means "needs attention now" (DD-017); throwing away is calm.
