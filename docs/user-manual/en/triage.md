# Processing your inbox

As soon as your inbox contains items, the button **Process · N** (N is the number of items in the
inbox) appears below the item count. That button opens the processing screen **Process**: you go
through your inbox card by card and give each item a place. You can also start the same screen
from **Today**, with the button **Process** on the line for your inbox there, see
[Today](today.md).

At the top right you see "3 of 12": the card you are on, and the total. If you capture a new item
while processing, it goes to the back and counts towards the total. Below it a progress bar moves
along.

At the top left is a cross (✕, tooltip "Stop") with which you can stop at any moment: what you have
already chosen stays; items you have not got to yet or have skipped simply stay in the inbox.

## One card at a time

Every card shows:

- the **title** (the first line, without the signs `@`, `#` and `!`);
- the rest of the text below it, which scrolls inside the card if it does not fit;
- if the item already has a type, the type chip (icon and name, for example ☑ **Task**), see
  [Capturing something](capturing.md);
- the chips for person, tags and date;
- how long ago you captured the item;
- the line "Looks like another item", if that applies to this item, see
  [Capturing something](capturing.md);
- the button **Open**, which opens the item to see or edit the full text; if you go back, you are on
  the same card again.

## Choosing a project

Above the six buttons is a project chip. Tap it (Windows: key **P**) to open the **Project** window
and give the item a project, see [Projects](projects.md). Choosing a project does not process the
card: you still choose a destination afterwards.

## Six destinations

Below the card are six buttons, in two rows:

- **Task**, **Idea**, **Request**
- **Wait for**, **Note**, **Trash**

What each button does:

- **Task** — type **Task**, status **Active**.
- **Idea** — type **Idea**, status **Active**.
- **Request** — type **Request**, status **Active**; Offload first asks "Who asked for this?".
- **Wait for** — status **Waiting**, the type stays as it was; Offload first asks "Who are you
  waiting for?".
- **Note** — type **Note**, status **Active**.
- **Trash** — the item goes to the trash; you can undo this.

### Later…

Below the six buttons is the text button **Later…** (Windows: key **6**). It opens the choice list
**Revisit on**, see [Parking an item](revisit.md). The item leaves your inbox, gets the status
**Scheduled** and comes back on the chosen day. It counts as processed and you can undo it like any
choice.

### Who asked for this? / Who are you waiting for?

With **Request** and **Wait for**, a window with a name field (**Name**) opens first, with
suggestions of people you already know (also names with a space in them) and, if the name does not
exist yet, "New: «name»" to create someone new.

- With **Wait for**, below the name field is the optional line **Expected by…** ("optional"):
  choose in the calendar when you expect it. If you skip this, the item has no expected day. See
  [Viewing and editing an item](item-detail.md#commitment).
- **Skip** chooses the destination without linking a person.
- **Done**, or Enter in the name field, chooses the top suggestion (a known person goes before a
  new one).
- Whoever you choose, you then see as a person in the item and under **People**, see
  [People](people.md).
- If you close the window (for example with back, or by tapping next to it), nothing is chosen and
  the card simply stays; you can then try again.

## Swiping (Android)

On Android you can also swipe a card away:

- to the **right** — **Skip**: the item stays in the inbox, you go to the next card.
- to the **left** — **Trash**.

On Windows this is not possible with swiping yet; use the buttons or the keys below there.

A screen reader (TalkBack on Android, Narrator on Windows) offers the actions "Skip" and "Trash" on
every card, even without swiping.

## Undo

After every choice you see a message, for example "Moved to Task" or "Moved to trash", with the
button **Undo**. That only undoes the last choice, and only once: if you carry on after that, you
cannot go back any further. On Windows, **Ctrl+Z** does the same. The message disappears by itself
after five seconds; if you use a screen reader (TalkBack), it stays until you tap **Undo**; if you
choose the next card, that message immediately takes the place of the previous one, which you then
can no longer undo.

## At the end

When you have been through all the cards, you see "Everything has a place" with how many items you
have processed ("N processed") and, if you skipped any, also "N skipped, still in your inbox". The
button **Back to the inbox** takes you back; if you started processing from **Today**, this button
is called **Back** and takes you back to **Today**.

## Keyboard shortcuts (Windows)

- **1** Task, **2** Idea, **3** Request, **4** Wait for, **5** Note — also on the numeric keypad;
  the digit is shown on every button.
- **Del** — Trash.
- **→** or **space** — Skip.
- **Ctrl+Z** — Undo.
- **6** — Later…
- **P** — Choose project.
- **Enter** — Open.
- **Esc** — Stop.
