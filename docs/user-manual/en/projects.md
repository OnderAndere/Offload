# Projects

With projects you group items that belong together. You find them under **Projects**, the third
place in the navigation, see
[Switching between Today, Inbox, Projects, People and Insights](navigating.md). On Windows you also
get there with **Ctrl+3**.

An item belongs to at most one project. A project can have sub-projects, but not deeper than two
levels.

## The list of projects

The list begins with a row **Without project** (with a dashed line around it): all items that
belong to no project are there, including items you have already processed. Below it are your
projects in alphabetical order, with their sub-projects indented below them.

Every row shows the number of open items: items that are not done or archived. Notes do not count.
A main project also counts the items of its sub-projects. If there are items with a deadline that
has already passed, the number of them is shown next to it in orange, with a warning icon.

At the bottom, if you have any, is "Archived · n". Tap it to show the archived projects or collapse
them again.

### Creating a project

Tap **+** in the bar at the top. The window **New project** asks for a name and, if you want, under
**Under** the main project it goes beneath. If you leave that on "Top level (no parent)", it
becomes a main project.

If a project with that name already exists at the same place, you see "There is already a project
with this name." Archived projects do not count here.

## Opening a project

Tap a project to open it. At the top are the sub-projects as chips; tap a chip to open it. Below
that are the items of the project itself, grouped by status: **Inbox**, **Active**, **Waiting
for**, **Scheduled** and **Notes**. **Done** is collapsed; tap it to show it. You do not see
archived items.

The cards are the same as elsewhere, see [Capturing something](capturing.md). Tap a card to open
the item, see [Viewing and editing an item](item-detail.md). Within the project, the card does not
show the project itself.

- **Android:** swipe a card to the left to move it to the trash, with **Undo**. You go back with
  the arrow at the top left or the back button of your device.
- **Windows:** **Delete** moves the chosen card to the trash. You go back with "‹ Projects" at the
  top left, with **Esc** or with **Backspace** (if you are not typing).

Below the title is the button **Where was I?**, to record where you left off with this project; the
note then appears as a card at the top, see [Where was I?](where-was-i.md).

## The menu of a project (⋮)

- **Rename** — gives the project a different name.
- **Move…** — puts the project at the top level or under another main project. A project that has
  sub-projects itself stays at the top level.
- **Archive** — archives the project, and its sub-projects go with it. You see "Project archived"
  with **Undo**.
- **Delete** — Offload first asks for confirmation. The items remain but then have no project. Sub-projects
  become main projects. You see "Project deleted" with **Undo**.

For an archived project the menu has **Restore** and **Delete**. Restore also brings back the
sub-projects that were archived together with the project. If the name has been used by another
project in the meantime, the restored project gets a number, for example "Renovation (2)".

## Giving an item a project

- **In the item:** next to the chips for status and type is a third chip, with **No project** or the
  name of the project. If the project is archived, it says "Name (archived)". Tap it to choose a
  project, see [Viewing and editing an item](item-detail.md).
- **With `^` in the text:** type `^` and the name of the project, for example `^renovation`, see
  [Capturing something](capturing.md). A project that you choose later wins over that word. If the
  project does not exist yet, a chip **no project** says so, and you can create it in the item
  detail from that chip.
- **While processing:** on the card, a project chip is above the six buttons (Windows: key **P**).
  Choosing a project does not process the card; you still simply choose a destination afterwards,
  see [Processing your inbox](triage.md).

The chip opens the **Project** window:

- A field **Search or type a new name** filters the list while you type.
- **No project** takes the item out of its project.
- Below that are the projects, with sub-projects indented.
- At the bottom is "New project: «name»", with what you typed, to create and choose that project
  straight away. If the field is empty, it says "New project…"; that opens the **New project**
  window.
- **Enter** in the field chooses the first project whose name matches; if there is none, Offload
  creates the project.

## Projects on cards and in search results

On **Today** and in the **Inbox**, a card shows the project as a grey chip, after the type. In
search results, the project is below the date of capture, see [Search](searching.md).

A new item goes to the inbox. If you type `^renovation` with it, it is in that project straight
away, see [Capturing something](capturing.md). You find processed items again under **Projects**,
in their project or under **Without project**.
