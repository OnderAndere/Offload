# Switching between Today, Inbox, Projects, People and Insights

Offload currently has five places: **Today**, see [Today](today.md), **Inbox**, see
[Capturing something](capturing.md), **Projects**, see [Projects](projects.md), **People**, see
[People](people.md), and **Insights**, see [Insights](insights.md).

## Android

At the bottom of the screen is a bar with **Today**, **Inbox**, **Projects**, **People** and
**Insights**. On **Inbox** there is a round number with the number of unprocessed items, as soon
as there are any; a screen reader announces this as, for example, "3 unprocessed items". At the
bottom right of the screen is the **Capture** button, in both places.

If you are on **Inbox** and press the back button of your device, you go to **Today** instead
of Offload closing; from **Today** the back button closes Offload as usual.

## Windows

On the left is a bar with, from top to bottom: the **+** button (opens the capture screen, just
like **Capture** on Android), below it **Today**, **Inbox**, **Projects**, **People** and
**Insights**, and at the very bottom the cog for **Settings**. Here too, **Inbox** shows the
number of unprocessed items.

Above the list of Today or the Inbox is a search field ("Search items and people"); while you
type in it, the search results replace the list, see [Searching](searching.md).

From a wide window width, the list and an opened item sit side by side: if you click a card or
search result, it opens on the right, where you can edit right away; if nothing is selected,
you see "Choose an item" with the explanation "With the mouse, or with ↑ and ↓ in the list." If
the window is narrower, an item opens over the list (the bar on the left stays); if you then
make the window wide again, that item moves to the right part.

## Help on each screen

In the title bar of **Today**, **Inbox**, the capture screen, an item, processing your inbox, the
weekly review, **Projects**, a project, **People**, a person, **Insights**, search and
**Settings** is a **?** (tooltip **Help**; on Windows **Help (F1)**). It opens the manual at the
chapter or heading that belongs to that screen. See [Settings](settings.md#help) for how to move
around in Help.

On Windows, **F1** does the same for the screen that has the focus.

### Keyboard shortcuts

Everywhere, also while you type in a text field:

- **Ctrl+1** — to Today.
- **Ctrl+2** — to Inbox.
- **Ctrl+3** — to Projects.
- **Ctrl+4** — to People.
- **Ctrl+5** — to Insights.
- **Ctrl+N** — opens the capture screen.
- **Ctrl+F** — jumps to the search field.
- **Ctrl+Shift+W** — starts the [Weekly review](weekly-review.md).
- **Ctrl+Shift+P** — opens **Where was I?** for the item or project that is open or selected,
  see [Where was I?](where-was-i.md).

If you are processing (see [Processing your inbox](triage.md)), **Ctrl+1**, **Ctrl+2**,
**Ctrl+3**, **Ctrl+4**, **Ctrl+5** and **Ctrl+F** do nothing; **Esc** first stops the
processing.

### In the list

While the list (of Today or the Inbox) has the focus, not a text field:

- **↑** and **↓** — select a card.
- **Enter** — opens the selected card: in a wide window the focus goes to the opened item on
  the right, in a narrower window it opens as its own screen, see
  [Viewing and editing an item](item-detail.md).
- **Delete** — moves the selected card to the trash, with **Undo**; the next card is then
  selected.
- **Ctrl+Enter** — only on Today: completes the selected card, with **Undo**; the next card is
  then selected.
